# M1.5 manual test (profile editing, first real deployment)

Setup: the dev mesh must run the M1.5 server build (`directory.update`): in `otter-server`, `scripts/dev-mesh.sh stop`
then `scripts/dev-mesh.sh` again (data kept). Phones: phone A over `adb install -r`, phone B via
`python3 -m http.server 8000` in the APK's directory (port 8000 is open in the PC firewall). Emulator: a mesh advertised
as `127.0.0.1` plus `adb reverse tcp:<port> tcp:<port>` (see [M3](m3-manual-test.md)); `adb input text` cannot type
Cyrillic, so emulator renames use Latin names, and long links must be typed in chunks of ≤ 60 characters.

Result column: the 2026-11-11 emulator run (`Medium_Phone_API_35`, **staging** build = R8) against a 3-node scratch
mesh, with one scripted member (JVM client) watching the contact name. "—" = not run yet (needs the two phones / VPS).
